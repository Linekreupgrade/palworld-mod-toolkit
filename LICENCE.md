## 🧩 About

**Palworld Mod Toolkit** is a curated list of Palworld open-source tools:

- **Mod Menus** — ESP, item spawner, stat editor, fly mode, teleport, instant capture
- **UI Automation Bots** — resource farming bots, auto-catch, input helpers for single-player study
- **Quality-of-Life Mods** — inventory editor, weight removal, fast travel unlocker, overlay helpers
- **Research Frameworks** — spawn manipulation and config notes for educational use

Based on publicly available community tools like **Palworld Mod Menu**, **Palworld Trainer**, and **QoLMod**.
